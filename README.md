# Personal Finance Manager (Scala Course Project)

## Project Goal
Build a desktop app that helps users manage personal finances by tracking expenses, controlling monthly budgets, and reviewing spending trends.

## Core Features
- Add, edit, and delete expenses
- Organize expenses by categories
- Configure monthly budget limits
- Show spending statistics and charts
- Export transactions to CSV

## User Interface
- Dashboard with monthly summary
- Transaction list view
- Charts and statistics view

## Architecture
1. Presentation layer (JavaFX UI)
2. Domain layer (business and budget logic)
3. Data layer (SQLite)

## Team Work Split
1. UI and navigation (JavaFX views, forms, dashboard)
2. Financial logic (validation, budgets, summaries)
3. Persistence + analytics (SQLite, charts, CSV export)

## Technologies
- Scala (JDK 25, Scala 3.8.X, SBT)
- JavaFX
- SQLite

## Development Milestones
1. MVP: add expenses + transaction list + file/database save
2. Budget module: monthly limits + alerts + summary metrics
3. Analytics module: charts + category stats + CSV export
